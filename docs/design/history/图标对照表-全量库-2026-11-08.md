## 一、为什么重做

上一版（`分类图标映射-2026-11-08.md`）每格只给 3–5 个候选，那是我按语义猜的推荐。用户 11-08 反馈：**「AI 的图标对准差点意思」**，要求「不要精选，要全部 Fluent3D 包」。

所以这一版不预设推荐：整包 1545 张全部铺开，逐行由人指定；选中项与「含义」一起导出，我按清单写进 App。

## 三、怎么用

1. 双击 `assets/emoji/icon-picker.html`（Chrome / Edge / Safari 都行，不需要服务器）。
2. 左栏点一个分类 → 右侧点一个图标即落定，自动跳下一个未定项。
3. 同一个图标不确定时，搜索框输中文（`咖啡`、`猫`）或英文（`Croissant`）；回车＝直接落定第一个结果。
4. 含义不对就在文本框里改，随清单一起导出。
5. 全部定完点「生成清单」，整段复制发回；或「下载 JSON」。

进度与勾选存在浏览器 `localStorage`，关掉再开还在；「重置」清空（含新增的分类）。

## 三之二、加二级分类（页面内直接加）

每个「二级 · X」分组标题右侧有 **+ 新增**，点了填三样：

| 字段 | 规则 |
|---|---|
| 名称 | 必填，2–6 字；同一父级下不能重名 |
| key | 写进代码的标识，默认 `food.new` / `home.new`（同父再加自动变 `.new2`）；只能小写字母数字，格式 `父级.后缀`，全局唯一 |
| 含义 | 可留空；建议写清边界（例：奶茶不算「饮料」还是算） |

加完自动选中这一行，右侧点图标即落定。之后还能在编辑区**改名**；删除要点两次（行尾 `×` 或编辑区「删除」，第一次变成「确认」，3 秒内再点才真删），「重置」同理。

> 2026-11-10 修正：浮层、确认、导出都改成**页面自绘**，不再用 `<dialog>` / `confirm()` / 直接触发下载。原因：WorkBuddy 预览面板把页面放进沙箱 iframe，这三种能力会被浏览器静默拦掉，表现为「点新增没反应、点下载没反应」。

导出：底部「生成清单」打开浮层，可在**清单 / JSON** 之间切；**「复制」是主路径**（预览面板里下载常被拦），下载按钮在普通浏览器里可用。清单多一列「新增到」：内置分类留空，新增的分类写明父级 key，例如

```
food.new    奶茶    BubbleTea    喜茶、霸王茶姬，和咖啡分开      food
```

## 四、交回什么

制表符分隔，一行一个槽位，未改过的也照实导出（等于「保持现状」）：

```
food   吃   Croissant   凡是进嘴的都归这里
```
