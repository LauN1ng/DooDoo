## 零、一句话

一屏三件东西：左上字标、右上分段 tab、下面一摞纸卡；纸卡最上面那张是「今天」，它的最后一行就是记一笔。

## 一、页面结构（390 × 844，圆角 44）

| 层 | 位置 | 内容 |
|---|---|---|
| 状态栏 | 0 ~ 46 | 时间 + 电池（原型占位） |
| 页头 `.hd` | **top 52，高 34**，左右 20 | 左：`DooDoo` 21pt/700；右：顶部 tab 112×34 |
| 卡堆 `.deck` | **top 116，bottom 8** | 卡片左右 16，圆角 24 |
| 便签 | 卡内 `right:6; top:-14`，旋转 −3° | 只在「今天」那张卡 |

**页头与卡堆之间留 30pt**：卡顶 116 − tab 底 86 = 30。这个 30 不是随手写的——便签顶在 99.6，必须离 tab 底（86）**≥12pt**，由此反推出卡堆顶 116（见 3.3）。

## 二、顶部 tab（T1 灰槽白块）

### 2.1 尺寸

| 项 | 值 |
|---|---|
| 容器 | **112 × 34**，圆角 17，内距 2，底色 `#EBE7E0` |
| 段 | **36 × 30**，圆角 15，三段等宽（不按内容收缩） |
| 图标 | 17pt 线性；选中 `#1D1C1A`，未选 `rgba(29,28,26,.38)` |
| 选中块 | `#FFF` + `inset 0 0 0 .5px rgba(29,28,26,.10)` + `0 1px 2px rgba(29,28,26,.10)` |
| 右内距 | 20（与字标左内距对称） |
| 字标↔胶囊 | 实测 157.9（要求 ≥60） |

### 2.2 三段

`流水`（默认选中）/ `资产` / `设置`。**没有 `还款`**。

- 三个图标均为 17pt 线性、1.7~1.9 描边：列表三横、钱包、齿轮。
- 选中态**只换填充色**：不加位移、不加下划线、不加放大（浅底上「抬起」实测无效）。
- 已有先例：资产页顶部同款胶囊里写的是「流水 / 资产」文字，本次统一为图标；两处必须一致。

### 2.3 为什么不是墨色、不是裸图标

- 墨槽（`#1D1C1A` 实心）能读，但与 21pt 字标对撞，页头出现两个重物。
- 裸图标去掉了容器，「三个里选一个」读成「一个按钮」——容器才是层级的载体，颜色只是强度。
- 浅色容器浮白卡必糊（色差 <5%），这条已被否过两次；槽色只能比页底**更深**。

## 三、卡堆

### 3.1 张数与首次使用

| 规则 | 值 |
|---|---|
| 张数 | **min(有数据的天数, 7)**，上限 7（一周） |
| 首次使用 | **只有 1 张**，不补空卡；空状态文案「还没有记账 / 下面那一行就是入口」 |
| 卡顶 | 恒为 116（不随张数动） |

### 3.2 叠法（S1：可见层封顶 4 张）

| 规则 | 值 |
|---|---|
| 层厚 | **恒定 10pt**，不压缩（5pt 比 24pt 圆角还薄，读不出层） |
| 可见层 | **封顶 4 张（3 条边）**；更深的卡不渲染 |
| 前卡底距屏 | `max(34, 8 + 10 × min(N−1, 3))` |
| 卡高 | `720 − (前卡底距屏 − 8)` |
| 后层装饰 | `rotate(−1.0° / 0.9° / −1.3°)`、`translateX(−5 / 4 / −4)` |

| 张数 N | 画出 | 层厚带 | 前卡底距屏 | 卡高 |
|---|---|---|---|---|
| 1（首用） | 1 | 0 | 34 | 694 |
| 2 | 2 | 10 | 34 | 694 |
| 3 | 3 | 20 | 34 | 694 |
| 4 | 4 | 30 | 38 | 690 |
| 5 ~ 7 | **4** | 30 | 38 | 690 |

**为什么封顶 4**：7 张全画就是 6 条等距白边 + 6 层描边，读成「一沓空白卡片」。纸叠的质感来自「有一点厚度」，不来自「数得清几张」。
**代价**：「有几天」不再由层数读出（日期在卡上，滑动也能知道）。

**34 的来源**：iOS Home 指示条上沿。记账行是可点元素，必须落在安全区之上；1~3 张时层厚带撑不住，靠这个下限兜住。

### 3.3 便签

- 位置：**卡内** `right:6; top:-14`，`rotate(-3deg)`，底色 `#FFF7E0`、描边 `#EFE2BE`。
- 只在「今天」那张卡显示，翻到历史日即消失。
- 文案：`本月 ↘ 12.4%`（口径见 `history/设计方向-卡片堆叠` 3.5.2 的 MTD 同期）。
- **硬约束**：便签 bbox 顶 = 卡堆顶 − 14 − 3.6（旋转外扩）。卡堆顶 116 ⇒ 便签顶 99.6 ⇒ 与 tab 底 86 相距 **13.6pt**。

### 3.4 后层不渲染内容

只画纸边，不渲染流水行。7 张若都铺内容等于 56 个 emoji、7 份 DOM——看不见的东西不该存在。

## 四、记账行（记一笔 = 今天卡的最后一行）

### 4.1 位置与尺寸

| 项 | 值 |
|---|---|
| 位置 | 今天卡内部，`rows` **之外**（不随滚动），卡片 padding 16 之上 |
| 行高 | **56**，宽 326（卡宽 358 − 左右 16） |
| 结构 | 42×42 槽 + 12 间距 + 「记一笔」14pt/500 `rgba(29,28,26,.62)` + 右侧「今天」11pt `#A8A39A` |
| 卡内 `padding-bottom` | **16**（该行自己撑起底部，不再沿用旧的 76） |
| 底距屏 | 54（N=4）；N=1 时 50 |

### 4.2 槽：B2 空分类位（2026-11-08 定案）

| 项 | 值 |
|---|---|
| 尺寸 | **42 × 42**，圆角 13 |
| 底 | **`#F6F3EC`**（与记账页分类格同一个底） |
| 描边 | **无** |
| 图标 | plus 15pt，`rgba(29,28,26,.34)` |

**为什么不是虚线框**：虚线是页面里全新的一套语汇，别处一条虚线都没有；而「空分类位」这个意思，分类格本来就在表达——空着就是可以往里填。

已否决的替身（不再讨论）：B1 虚线槽、B3 纯文字行（丢失 42pt 图标节奏）、B4 纸面按钮（又变回「物体」）。

### 4.3 文案与日期语义

| 当前卡 | 左侧文案 | 右侧 |
|---|---|---|
| 今天 | 记一笔 | 今天 |
| 历史日 | 记一笔 | `11月3日` |

点历史日的这一行 = **给那天补记**（`Transaction.date` 预填该日），不弹「请选择日期」。

### 4.4 点击行为

整行可点（命中区 326×56），进**半屏记账面板**（支出/收入/还款/转账 → 金额 → 8 分类 4×2 → 账户药丸 → 评分四档 → 16 键键盘）。面板本身不在本规格范围内。

## 五、资产页账户堆（与之配套的另一条规则）

层数 = **min(账户数, 3)**；容器高 = `84 + 16 × (层数−1)`；前卡底距容器底 = `16 × (层数−1)`；账户数 = 1 时不显示数量角标。
层厚 **16pt**（资产卡 82 高、圆角 13，10pt 会掉进圆弧读不出层）。详见 `资产页规格冻结-v1.0.md` 顶部修订提示。

## 六、SwiftUI 契约

```swift
// 顶部 tab：自绘分段控件（系统 Picker 对不齐 34pt / 17 圆角 / 半像素描边）
struct TopTab: View {
    @Binding var tab: RootTab          // .flow / .assets / .settings
    var body: some View {
        HStack(spacing: 0) {
            ForEach(RootTab.allCases, id: \.self) { t in
                Button { tab = t } label: {
                    Image(systemName: t.icon)
                        .font(.system(size: 17))
                        .frame(width: 36, height: 30)
                        .foregroundStyle(tab == t ? Color.ink : Color.ink.opacity(0.38))
                        .background {
                            if tab == t {
                                RoundedRectangle(cornerRadius: 15).fill(.white)
                                    .shadow(color: .ink.opacity(0.10), radius: 1, y: 1)
                                    .overlay(RoundedRectangle(cornerRadius: 15)
                                        .strokeBorder(.ink.opacity(0.10), lineWidth: 0.5))
                            }
                        }
                }.buttonStyle(.plain)
            }
        }
        .padding(2)
        .frame(height: 34)
        .background(RoundedRectangle(cornerRadius: 17).fill(Color(red: 0.922, green: 0.906, blue: 0.878)))
    }
}

// 卡堆：只构建前 3 层 + 前卡，其余不给 View
struct DayDeck: View {
    let days: ArraySlice<DayCard>      // 已按「老 → 新」排好，最多取最后 4 个
    var body: some View {
        let n = min(days.count, 4)
        let band = 10 * (n - 1)
        let frontBottom = max(34, 8 + band)
        ZStack(alignment: .bottom) {
            ForEach(Array(days.enumerated()), id: \.offset) { i, day in
                DayCardView(day: day, isFront: i == days.count - 1)
                    .padding(.horizontal, 16)
                    .padding(.bottom, CGFloat(frontBottom - 10 * (days.count - 1 - i) - 8))
                    .rotationEffect(.degrees(i == days.count - 1 ? 0 : [-1.0, 0.9, -1.3][i % 3]), anchor: .bottom)
                    .offset(x: i == days.count - 1 ? 0 : [-5, 4, -4][i % 3])
            }
        }
    }
}

// 记账行：固定在卡内 rows 之外
AddRow(slot: .emptyCategory, label: "记一笔", trailing: isToday ? "今天" : "\(month)月\(day)日")
    .frame(height: 56)
```

## 七、明确不锁定（端侧可再调）

> 用户 2026-11-08：叠法「差强人意，但可以先写进去，端侧再具体修改」。以下项允许在真机上改数值，**不必重走冻结流程**，改完回写本文。

| 项 | 当前值 | 可调范围 | 约束 |
|---|---|---|---|
| 层厚 | 10 | 8 ~ 12 | 必须 > 卡圆角的一半观感阈值，且 4 层总高 ≤ 40 |
| 可见层数 | 4（3 条边） | 3 ~ 5 | **不得回到 7 张全画**（已否决） |
| 层边不透明度 / 描边 | `rgba(29,28,26,.11)` | .08 ~ .16 | 太淡会丢层，太浓变手风琴 |
| 槽的圆角 | 13 | 12 ~ 14 | — |
| 槽底 | `#F6F3EC` | 可在 `#F4F1EA ~ #F7F4EE` 间微调 | 不得加描边（会退回 B1/B4） |
| 行右标签 | 11pt `#A8A39A` | 字号 10.5 ~ 11.5 | — |
| **卡片左右内距** | **20**（2026-11-08 真机调整，规格原值 16） | 16 ~ 24 | 按 390pt 设计稿的 16 在 402/440pt 真机上占比变小、读起来像贴边；调大后仍须保证卡内文字左右 18pt 不缩 |

> 2026-11-08 真机验收补录：① 页头与状态栏必须是页面底色 `#F7F5F1`，**不能用系统白**——白页头 + 白卡片会连成一片，看起来像"顶上多出一块白"；② 前卡投影从 `0 10 28 /.045` 加强到 `radius 18 / y 10 / .08`，否则白卡在米底上立不住。
>
> 2026-11-09 真机反馈补录（1.x 端侧可调）：卡堆手势方向定为 **右滑 = 翻到昨天（更早）、左滑 = 回到今天（更近）**。v1.0 正文与快照都未定义方向，首版实现把两个分支做反了；此项按第七节「端侧可再调」处理，不改快照、不改视觉。

## 八、变更规则

- **1.x**：只改第七节的项 + 对应表格；快照与哈希重新生成。
- **2.0**（改结构：tab 数量、入口类型、卡堆上限、卡片半径）：需用户确认，出新快照 + 本文升版。
