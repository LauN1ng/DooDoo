# 记一笔规格冻结 v1.0

## 四、四类型字段差异

| 区块 | 支出 | 收入 | 还款 | 转账 |
|---|---|---|---|---|
| 卡池 | 全部账户 | **仅储蓄** | **仅信用/借款** | 双卡并排（从 → 到，158×100 两张） |
| 归属行 | `从 花呗 · 账单期 11/15–12/14 · 计入 12 月`（信用）/ `储蓄账户 · 立即扣款` | `存进 建行 5044 · 储蓄账户 · 余额增加` | `还 花呗 · 11 月账单 · 第 3 期` | — |
| 分类 | 一级 8 类 + 二级（第六节） | 一级 2 类 + 二级 | 无 | 无 |
| 评分 | 有（第七节） | 无 | 无 | 无 |
| 金额 | 1 个 | 1 个 | 1 个（默认带出本期应还） | **2 个**：转出、到账 |
| 特有块 | — | — | ① `本期应还 ¥x · 剩余 n 期 · 不计支出`；② 扣款卡横滑（112×72） | `手续费 ¥x = 转出 − 到账 · 差额自动记一笔支出` |
| 余额预览 | 单行：该账户余额/欠款变化 | 单行：余额增加 | 双行：欠款变化 + 扣款卡余额变化 | 双行：转出方、转入方 |
| 主按钮 | 记下这笔 | 记下这笔 | 确认还款 | 确认转账 |

硬规则（不得因界面合并而模糊）：

1. 还款 `kind = .repayment` **完全不计支出**；转账 `kind = .transfer` 只有手续费差额计入支出（分类暂映射「其他」，见第十节遗留）。
2. 还款必须关联 `BillStatement` 期数（PRD v2.0）；转账不关联。
3. 收入没有评分（PRD 9.13：只有 `kind == .expense` 可评分）。

## 五、金额与手续费

- 支出 / 收入 / 还款：单一金额，键盘直接输入。
- 转账：**转出、到账两个独立输入框**，点谁谁出现光标；`手续费 = 转出 − 到账`（负数按 0 显示并提示）。
- 手续费的费率规则**不在本规格内**（待讨论，见 PROGRESS 未闭合项）；本规格只定「差值展示」这一交互。

## 七、评分（仅支出）

- 四档 chip：夯 / 飘 / 拉 / NPC + 「跳过」；选中主色实底白字；跳过 = `nil`（不是 NPC）。
- 默认带出 `Category.defaultGrade`（该分类上次档位）。
- 收入 / 还款 / 转账不出现评分区。

## 八、保存行为

1. 校验：金额 > 0；还款需有可关联账单期（M3 起）。
2. 写入走 `LedgerService`（AGENTS 7.2），软删除、`recalculateAll()` 照旧。
3. 保存后面板关闭，回到流水页当天日卡，新行在列表顶部高亮一次。
4. 「再记」= 保存后保留面板、清空金额，其余默认值重新带出。
