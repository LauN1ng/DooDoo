## 一、结论先行

1. **你是对的：App 内页就是灰白底 + 纯白卡。** 我 11-14 查 Copilot Money **官网**（近黑 `#000814` + 信号蓝 `#1C6CFF`）查错了对象——**官网 ≠ App 内页**。实图底色是 `#F6F6F6` / `#F4F4F4`，白卡 `#FFFFFF`。
2. **底色是完全中性灰（R=G=B），无暖黄、无蓝紫。** 我前两轮给的 `#F2F2F3`（微蓝）和 `#F5F5F7`（蓝紫）都偏色；实图是纯中性 `246/246/246` 与 `244/244/244`。
3. **主色不是「一个色」，是一组语义色**：绿（正向/主数字/CTA）、红（支出/负值）、蓝（链接）、橙（汇总）、紫（转账）、浅绿底（横幅）。而且**敢用大色块**（图 2 整块红/绿汇总卡）。这推翻了我按官网推的「一个主色只出现 2 处」——`home-m4-v2` 太克制，难怪连续三轮「都不对」。
4. **11:26 用户已澄清产品名**：上轮 03/04 = HeyCost，新补 2 张 = Copilot Money；上轮 01/02 未指定，标「未确认组」。三套体系的取色与差异见「三·补」。
5. **大数字是绝对主角**：净资产 `¥5,890`、`¥550.00`、支出 `¥2` 都是 28–40pt 粗体，第一眼是数字不是装饰。

- 内容区：白卡大圆角（≈20pt）+ 宽松间隙、几乎无描边，靠明度差读层次
- 卡片内：**大数字**（`$37,396` / `$946 left`）+ 绿色折线 + 区间 pill（1W/1M/3M/YTD/1Y）
- 彩色只给：正向绿（数字/曲线/涨幅 pill）、**彩色分类 pill**（RESTAURANTS 橙 / GROCERIES 绿 / AUDIBLE 深绿）、**橙色预算环 + emoji**（🚗🥑🍔🎁💳）、蓝色链接文字
- 标题 / 正文 / 卡片底 / 分隔线全中性

### 三家共识（可以定）

1. 内容区 = **浅灰白底 + 纯白卡**，靠明度差 + 间隙 + 大圆角分层，**几乎无重阴影**
2. **大数字是主角**（28–40pt 粗体）
3. **彩色只给数据语义与内容**：绿=正向/曲线、彩色 pill=分类、emoji=内容层；UI 骨架（卡片、标题、线、槽）全中性
4. **语义色组而非单一主色** —— 再次印证本文第五节，也再次说明我前两轮「选一个主题色」的思路是错的

### 三家分歧（不能照抄）

- **品牌色区**：只有 Copilot 有蓝色渐变顶栏；DooDoo 冻结的是顶部 tab，**不做大色块 header**
- **主色蓝/绿**：各家品牌差异；DooDoo 保留自己的品牌绿作交互色，不必改成蓝
- **导航形态**：底部图标条 / 顶部横向胶囊 / DooDoo 顶部 112×34 三图标 —— 三种都不同，**结构不动**
- 预算环、图表分析、投资、demo 提示等产品范围外内容，PRD v1 不做

### 结论

「灰白底 + 白卡 + 语义色组 + 大数字」是共识骨架，**可以定**；**主色不需要再选**，沿用项目品牌绿并补齐语义色（正向绿 / 支出红 / 链接蓝 / 汇总橙）即可。11-14 悬着的「主题色不确定」由此解掉。

## 五、彩色到底用在哪（最重要的纠正）

| 位置 | 用色 | 面积 |
|---|---|---|
| 正向数字（可支配 / 收入 / 月均支出 / 净资产趋势里的值） | 绿 | 中小 |
| 支出 / 负值 / 负债 / 超支 | 红 | 中小，A 组可放大到整块卡 |
| 可点击文字（全部账本 / 日历 / 净资产趋势 / 结余） | 蓝 | 极小 |
| 分组汇总（现金账户 ¥5,998） | 橙 | 极小 |
| 转账金额 | 紫 | 极小 |
| 主 CTA（+ FAB / 立即领取 / 立即体验 / 立即体验横幅） | 绿 / 浅绿底 | 中 |
| 图表柱 / 日历格 / 心情 emoji | 绿 / 彩色 | 中小 |
| **标题、正文、卡片底、分隔线、图标槽** | **全中性** | — |

**结论**：这是**跟着数据语义走的色组**，不是「选一个品牌色贯穿」。彩色可以成块出现，但**只出现在承载数据的地方**；UI 骨架（卡片、标题、线、槽）一律中性。我前两轮做的「主色只出现 FAB 与 tab 选中段 2 处」是照 Copilot 官网的落地页纪律套 App，**方向错了**。
