## 一、结论先行

1. **这次用的是正确基线**：`home-v3.html` = 首页规格 v1.0 指定的工作副本，**顶部 tab 112×34 + 卡内记账行 56 高 + 卡堆层厚 10pt**。11-14 拿错的 `home-final.html`（底部 nav + FAB）已废弃，`home-m4-v2.html` 不作依据。
2. **只换配色，几何一字节不动**：详见第三节。这是「一个界面一个界面来」的第一屏。
3. 依据来自三家实机共识：**完全中性灰白底 + 纯白卡 + 靠明度差/间隙/大圆角分层 + 几乎无重阴影 + 大数字主角 + 语义色组**；彩色只给数据与内容，UI 骨架全中性。
4. **主色不再单选**：沿用项目品牌绿作交互/正向色，按数据语义分配颜色（支出红、正向绿、链接蓝、汇总橙、内容层彩色）。

## 二、改动后的 token 表

### 基础层（中性灰阶，六张实图的共识区间）

| 键 | 改前 | **改后** | 理由 |
|---|---|---|---|
| `page` | `#F7F5F1`（暖白） | **`#F6F6F6`** | 完全中性 R=G=B；实测区间 `#F4F4F4`（HeyCost）~ `#F8FAFA`（Copilot） |
| `card` | `#FFFFFF` | `#FFFFFF` | 三家一致，不动 |
| `tab slot` | `#EBE7E0`（暖灰） | **`#E9E9E9`** | 中性；属首页规格第七节「槽底色」**未锁定项**，可改 |
| `inset`（记账行槽 / 图标槽） | `#F6F3EC`（暖） | **`#EFEFEF`** | 中性，vs 白卡色差约 6%，不糊 |
| `line` | `#EFECE5` | **`#E8E8E8`** | 中性细线 |
| `ink` | `#1D1C1A`（暖墨） | **`#1D1D1F`** | 去暖调，近黑中性 |
| `ink2` | `#8A867D` / `#5F5E5A` | **`#5F5F66`** | 次文字 |
| `sub` | `#A8A39A`（2.51:1 ✗） | **`#6E6E76`** | **5.05:1 on 白卡 / 4.52:1 on 页底**，双处达标 |
| `shadow` | `rgba(29,28,26,.10/.05/.11)` | `rgba(29,29,31,.05/.035/.055)` | 中性冷灰、**调到极轻**，前卡 `.045 → .055` |

### 语义色组（全局定义；第一屏只用到标注项）

| 语义 | 值 | 第一屏 |
|---|---|---|
| 支出 / 负值 | `#C0392B`（项目既有暗红） | ✅ 支出合计 `−¥331.50` |
| 正向 / CTA / 激活 | **`#3ABF58`**（品牌绿） | ⬜ 本屏未出现，留资产页 / 记一笔 |
| 链接 / 可点击文字 | `#0768C9`（Copilot 实图值） | ⬜ 留详情页 |
| 汇总 | `#E09B2D` | ⬜ 留资产页 |
| 内容层彩色 | 分类图标底 `#FFF1E6` / `#EAF2FF` / `#F3EEFF`、Fluent 3D emoji、彩色卡面 | ✅ 全部**保留**（内容层，不属 UI 骨架） |
| 装饰便签 | 暖黄 `#FFF7E0` + 绿字 `#3B7A44` | ✅ 保留（唯一暖色点缀） |

> **两个绿的债**：`AccentStyle.green = #2FB344`（代码/规格）与「品牌绿 `#3ABF58`」长期并存。本方案**统一到 `#3ABF58`**，代码落地时把 `AccentStyle.green.hex` 对齐即可；属 `记一笔规格冻结-v1.0.md` 第九节未锁定项 1，**1.x 可改、不升 v2.0**。
> **白字按钮注意**：`#3ABF58` 做实底白字只有 2.39:1，故**只用于图形/数字/进度/激活态**；若后续屏需要实底白字 CTA，用墨黑或深绿 `#197A2E`（5.43:1）。
