## 一、结论先行

1. **灰白基底定下来**：`page #F2F2F3` —— 这是**你 11-08 自己选的浅冷灰**（`记一笔-参考三图-2026-11-08.md` 第 12 行、`entry-redesign.html:9` 实证），不是我上轮给的 `#F5F5F7`（偏亮偏蓝紫）。这一版补齐 **5 级冷中性灰阶**，卡内图标槽、标签底、分隔线全部跟着 token 走，解决上轮「只换桌布」的问题。
2. **主题色不需要推翻冻结规格**：`记一笔规格冻结-v1.0.md` 第九节「未锁定项 1：主色」明写「墨 / 绿 / 蓝 / 橙，**或新色**」，属 **1.x 可直接改**；代码 `AppSettings.swift:21` 的 `AccentStyle` 也已支持切换并落到 `EntryView` / `CategoryPicker` / `InstallmentEntryView`。所以本轮只是**选定默认 `accentId`**，不用升 v2.0。
3. **Copilot 值得抄的是纪律，不是色值**：一个主色只出现在 CTA / 选中 / 激活态；彩色全部留给分类标签、emoji、卡面内容。官网原文「Make every category your own with colors and emojis」——和 DooDoo 的 Fluent 3D emoji + 彩色卡面是同一套逻辑。项目 11-03 早期原型 `prototype-v2.html:410` 也写过「**零彩色 UI，颜色只从 3D Emoji 来**」，两条路线能对上。
4. **实测把绿色和橙色挡在门外**：原规格的绿 `#2FB344`（2.74:1）、橙 `#E09B2D`（2.36:1）做「主色实底白字」都**不达 4.5:1**（规格第 31 / 81 / 109 行就是这么用的）。本轮六个候选全部用达标值。

## 三、灰白基底 v2（六版共用，固定）

| 键 | 值 | 作用 | 实测 |
|---|---|---|---|
| `page` | `#F2F2F3` | 页面底 / 页头 / 状态栏 | vs 白卡色差 **11.1%** |
| `card` | `#FFFFFF` | 日卡 / 总览卡 / 面板 | — |
| `inset` | `#E9E9EC` | 卡内图标槽、标签底、余额预览条 | vs 白卡色差 **18.3%**（够深，不糊） |
| `line` / `slot` | `#E4E4E8` | 分隔线 / tab 槽 | vs 页底色差 **12.4%**（≥5% 硬约束） |
| `ink` | `#1D1D1F` | 主文字 | 16.83:1 on 白卡 |
| `ink2` | `#5F5F66` | 次文字 | 6.33:1 on 白卡 |
| `sub` | `#6E6E76` | 辅助文字 | **5.05:1 on 白卡 / 4.52:1 on 页底**（两处都达标） |
| `shadow` | `0 2px 12px rgba(29,29,31,.06)` | 白卡浮起 | 中性冷灰影，无暖调 |

> 上轮 D 版 `sub #737379` 在白卡 4.71:1 达标，但**直接写在页底只有 4.20:1** 不达标；本轮改 `#6E6E76` 两处都过线。

## 四、主题色六版（唯一变量）

| # | 名称 | hex | 白字对比 | 来源 / 判断 |
|---|---|---|---|---|
| 1 | 墨（现状默认） | `#1D1C1A` | **17.03:1** ✓ | 规格默认；最克制，接近 11-03「零彩色 UI」 |
| 2 | Copilot 信号蓝 | `#1C6CFF` | **4.53:1** ✓ | 参考原色；但拆解站明确「勿照抄」，仅作基准 |
| 3 | **项目蓝（微调，推荐）** | `#4364EE` | **4.89:1** ✓ | 规格蓝 `#4A6CF7` 只有 4.39 ✗，微调达标；同源不同值、不抄品牌色 |
| 4 | 绿（加深） | `#197A2E` | **5.43:1** ✓ | 规格绿 `#2FB344` 2.74 ✗；且与「收入绿 `#2E9E6B`」易混 |

## 五、主色贯穿规则（Copilot 纪律，六版一致）

主色**只出现在可交互 / 激活元素**，其余一律中性：

| 出现位置 | 形态 |
|---|---|
| 主按钮 / CTA | 主色实底 + 白字（规格第 31 行） |
| tab 选中段 / 分类选中 / 评分徽章 | 主色实底 + 白字 |
| 选中态浅底 / 「今天」标签 / 二级分类圆底 | 主色 **12% wash** + 主色描边 |
| 进度条 / 额度条 | 主色填充 |

**主色不出现**：普通标题、正文、金额数字、卡片背景、分隔线、曲线。曲线仍用「我有 `#4C8DF6` / 我欠 `#E8734A`」，支出 `#C0392B` / 收入 `#2E9E6B` 保持固定，彩色卡面与 Fluent 3D emoji 属**内容层**。
> 上轮诊断说「品牌绿只在 CTA 一处」，本轮不是把它铺满，而是**让它出现在所有该出现的地方**（选中、进度、徽章），同时严格不越界到内容层。

## 六、与既有事实的关系

- **不改几何**：卡片圆角 24 / 图标槽 13 / tab 17 / 字阶 / 层厚 全部不动，因此**不触发冻结规格 2.0**。
- **只定默认 `accentId`**：`AppSettings.swift` 已有 `accentId` 字段与 `AccentStyle`，选完改默认值即可；选项本身仍保留，符合规格第九节。
- **不动口径、不动数据、不动 Swift 代码**（本轮只出方案与原型）。
- 技能：`ui-ux-pro-max --domain color`（单主色 fintech 参考）+ `ios-hig-design`（4.5:1 / 44pt / 11pt / Dynamic Type）；Web 专属结论不采用。
