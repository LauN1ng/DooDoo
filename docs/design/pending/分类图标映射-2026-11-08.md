## 一、怎么用这份表

1. 打开 `assets/emoji/icon-map.html`，每个分类点一下换图标（不点＝采用推荐）。

3. 按清单改 `assets/emoji/categories.json` 与 `Category.emojiName`，本文件升为 `已冻结`。

## 五、需要先拍板的三件事

### 5.1 话费宽带缺二级

PRD 3.1.2 里「住」的收什么写了话费宽带，但二级只有 房租 / 水电 / 物业 / 家居 / 维修。话费要么落「住」且二级留空（规则上合法），要么补一个二级「话费」（总数变 49）。

**建议：补「话费」二级。** 理由：每月固定支出，留空等于在流水里看不见这笔；而它和「水电」语义不同，合并会让月度固定开销失真。若采纳，PRD 3.1.2 与二级总数需同步改为 49。

### 5.2 三个分类缺贴切图标

| 分类 | 现状 | 处理 |
|---|---|---|
| 裤子 | 精选集无裤子 | 补 `Shorts`（短裤）进 `picked/` |
| 理发 | 只有 Scissors / Razor | 补 `BarberPole`（理发店彩柱）、`PersonGettingHaircut`（剪发） |
| 物业 | 只有 OfficeBuilding | 补 `Construction`（施工）备选 |

每个约 33 KB，4 个合计 ~132 KB，对包体无影响。

### 5.3 「红包」重复出现

`social.redpacket`（情/红包，支出）与 `otherIncome.redpacket`（其他收入/红包，收入）同名不同 key。建议共用 `RedEnvelope`，方向由收支决定，不另配图标。

## 六、落地清单（确认后执行）

1. 补 4 个图标进 `assets/emoji/picked/`，`categories.json` 的 `picked.total` 同步 +4。
2. 重写 `assets/emoji/categories.json`：按本表替换 `categories` 段（v2.2 的子类结构作废），保留 `grade` / `action` / `accountKind`。
3. `Category` 模型加 `emojiName: String`（PRD 3.4 已有 `key` / `parentKey`，图标不参与业务逻辑，只做展示）。
4. 本文件状态改为「已冻结」，并在 AGENTS.md 冻结物登记表追加一行。
