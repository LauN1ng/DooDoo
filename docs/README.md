# docs/ 文档分区

> 分区即权威等级。**同一件事只允许存在于一个分区**，不要平铺同名文档。
> 规则见根目录 `AGENTS.md` 第三、四、五节。

---

## 一、分区表

| 目录 | 权威等级 | 放什么 | 能否据此写代码 |
|---|---|---|---|
| `product/` | 产品事实 | `PRD-v2.1.md`（已冻结） | ✅ 可以 |
| `design/spec/` | 实现依据 | 已冻结的视觉规格 | ✅ 可以 |
| `design/pending/` | 未定案 | 还在选方案的视觉文档 | ❌ 不可以 |
| `design/history/` | 历史 | 推演记录、被推翻的结论、旧决定 | ❌ 不可以 |
| `art/` | 资源事实 | 美术清单、交付记录 | ✅ 资源相关可以 |
| `reference/` | 只读证据 | 原始账单文本、提取脚本、样本 | ❌ 只作为测试数据 |
| `archive/` | 已废止 | 开工前决策清单 xlsx 及其生成脚本 | ❌ 不可以 |
