# DooDoo 卡面 / 图标 美术资源清单

> 2026-11-07 路径迁移：仅修正文内交叉引用路径，内容未改。
> 结论先说：真实感 **80% 来自排版和光影，不是来自图片**。现在这版卡面是纯 CSS 的（零图片），已经能"像"。真正需要准备的图像资源只有 **3 类、约 44 个文件**，不是一整个素材库。

---

## 一、先理解"像卡"的 5 个要素

| 要素 | 标准 | 现状 | 需不需要图 |
|---|---|---|---|
| 长宽比 | ISO/IEC 7810 ID-1 = 85.6×54mm = **1.586:1** | 148×92 = 1.609，差 1.5%，肉眼无感但可以改 148×93 | 否 |
| 结构位 | 芯片左上、卡号下部、品牌名右下、卡组织右下角 | 已按此排 | 否 |
| 光影 | 单一光源（左上）+ 边缘 0.5px 内高光 + 品牌色渐变（不是纯色） | 已做 | 否 |
| 字体 | 卡号必须 `tabular-nums` + 字距 `.09em`，尾号 4 位是主角 | 已做 | 否 |
| 纹理 | 磨砂 / 拉丝 / 微粒噪点，不透明度 2–4% | **没有** ← 这是最缺的一层 | **是** |

所以真正要补的图只有：**纹理 3 张、品牌标 17 个、分类图标 ~24 个**。

## 二、P0：必须准备（约 20 个文件）

### 1. 银行 / 品牌标（17 个）

- **格式**：SVG，单色版（`fill="currentColor"`），viewBox 24×24
- **尺寸档位**：24 / 48 两档导出，实际只用 12×12 渲染
- **放置位置**：卡面右上角，白色 `opacity:.7`，**不做彩色**（彩色标在窄卡上会花）
- **来源优先级**：
  1. [Simple Icons](https://simpleicons.org)（CC0 代码、商标归各家，个人自用无碍）
  2. 各家银行的"品牌资源 / 媒体中心"页面（招行、建行官网底部通常有）
  3. Wikimedia Commons 搜 `xxx logo.svg`
- **命名**：`brand-cmb.svg`、`brand-ccb.svg`、`brand-alipay.svg`、`brand-jd.svg`、`brand-wechat.svg`…
- **⚠️ 法律边界**：Logo 是注册商标。**本地自用、不上架没问题；上架 App Store 有被驳回或被投诉的风险。** 最低风险方案见第五节。

### 2. 卡组织标（4 个，可能一个都不需要）

- 银联 / Visa / Mastercard / 无（花呗、白条这类没有卡组织）
- **格式**：SVG **纯白单色**（官方彩色版放上去会很花，且偏离你现在的低饱和调性）
- **来源**：银联品牌中心、Visa Brand Center、Mastercard Brand Center 均有官方下载（附带使用条款）
- **建议：先别下载。** 用文字标（`UNIONPAY` 8px 字距 .09em）就能过，法律风险为零，我在原型里就是这么做的。

## 三、P1：性价比最高的一步（3 个文件）

### 卡面纹理（3 张）

这是"从扁平色块 → 真实卡片"唯一的断层。做法：品牌色渐变上叠一张低透明度纹理，`background-blend-mode: overlay`。

| 纹理 | 用途 | 规格 |
|---|---|---|
| 磨砂 `tex-matte.png` | 信用卡、储蓄卡 | 512×512，无缝平铺，PNG-24，<30KB |
| 金属拉丝 `tex-metal.png` | 分期贷、e招贷 | 1024×512，横向拉丝，<40KB |
| 微粒噪点 `tex-grain.png` | 全局叠加（不透明度 3%） | 256×256，<15KB |

- **来源**：① 自己用 ImageGen 生成"无缝平铺的哑光黑卡表面微纹理，灰度，无品牌无文字" ② 现成免费库 Subtle Patterns / Transparent Textures
- **不需要**：真实银行卡照片、卡面大图、3D 渲染图

## 四、P2：交易分类图标（~24 个）

现在的 emoji（🍰🚇🐱）是"不够精致"的最大来源：跨设备渲染不一致、颜色不可控、和卡面调性打架。

- **格式**：24×24 SVG，`stroke:currentColor`，`stroke-width:1.7`，圆角端点
- **套数**：只选一套，别混
  - Phosphor Icons（MIT，1200+）→ 推荐，圆润度和你的圆角体系匹配
  - Lucide（ISC）→ 更硬朗
- **需要的分类（24 个）**：餐饮 / 咖啡 / 外卖 / 地铁 / 打车 / 购物 / 服饰 / 日用 / 房租 / 水电 / 话费 / 医疗 / 药品 / 娱乐 / 订阅 / 数码 / 宠物 / 人情 / 学习 / 旅行 / 工资 / 奖金 / 还款 / 转账
- **落地方式**：36×36 圆角 12 的浅底（`#F6F4EF`）+ 20×20 图标，单色 `#6B6862`，选中态换品牌色

## 五、省时间 / 降风险的判断

**1. 用不上真实卡面照片。** 你 17 个账户，手里实体卡大概 3–4 张。只有 4 张能用照片、其余还得渐变，风格必然割裂。全部走"品牌色渐变 + 纹理"才不会散。

**2. 上架版换掉真实 Logo。** 三个方案，按风险从高到低：
- A（自用）：真实 Logo，不发布 → 现在这样
- B（推荐上架）：**品牌色块 + 银行名前两个字**（"招行""建行"），不用 Logo，零风险，视觉还更统一
- C：自己重绘"类标"→ 费力且仍可能被认为近似，不划算

**3. 先只做 3 张，别做 17 张。** 招行信用卡、花呗、建行储蓄卡——这三张覆盖了"银行红 / 互联网蓝 / 储蓄深蓝"三种类型。这三张像了，剩下 14 张只是改 `--c1/--c2` 两个变量；这三张不像，问题一定在排版或光影，加图也救不回来。

## 六、最终目录结构

```
assets/
  brands/     brand-cmb.svg  brand-ccb.svg  brand-alipay.svg  ...   (17)
  networks/   net-unionpay.svg  net-visa.svg  net-mc.svg             (3，可省)
  textures/   tex-matte.png  tex-metal.png  tex-grain.png            (3)
  icons/      cat-food.svg  cat-metro.svg  ...                       (24)
```

命名规则：`{类型}-{标识}.{扩展名}`，全小写、连字符。全部单色 SVG 用 `currentColor`，颜色由 CSS 变量控制——换主题不用重导资源。
