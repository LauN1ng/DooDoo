## 二、两条已定案规则

### 1. `chip`：只有实体银行卡保留芯片

`brands.json` 每个品牌带 `chip` 布尔值；账户可用同名字段覆盖（白条分分卡即 `chip: false`）。

- **10 张实体卡**（建行 ×2、招行 ×3、5 张新增大行样卡）：左上金属芯片 + 右上白色行徽。
- **14 张虚拟卡**（钱包 / 虚拟信用 / 分期贷 / 现金）：**去掉芯片，但仍是完整卡片形态**，行徽放大到左上，右上换类型标签（SAVINGS / CREDIT / LOAN / CASH）。

依据：用户 2026-11-08 定案「这种不需要芯片但是要卡片，但是也要 logo」。

### 2. `logo`：A 单色白色行徽

先用建设银行出 A/B/C 对比图（`design/current/_card-logo-ccb-compare.html` / `.png`）定案，选 A。

- **A（采用）**：官网 logo 裁出左侧行徽 → 压成白色单色透明矢量。视觉统一、窄卡不花、换主题不用重导。
- B（否决）：官网彩色整条 logo + 白底衬，在渐变卡上是贴纸感，且 130×26 时中文发糊。
- C（否决）：Simple Icons 无六大行；Commons 的 `People Construction Bank of China logo.svg` 是 `#ED1C24` 红色老标，版本和颜色都不对。

## 四、15 枚行徽来源

| 来源 | 数量 | 明细 |
|---|---|---|
| 各行官网 logo PNG 裁切 | 10 | 工行 / 农行 / 中行 / 建行 / 交行 / 邮储 / 招行 / 上行 / 中移动 / 京东 |
| Simple Icons 矢量 | 3 | 支付宝 / 微信 / 抖音（与 TikTok 共用音符标） |
| **用户提供的官方图标截图** | **2** | **余额宝（橙红元宝鱼 + 金黄小圆点）、花呗（亮蓝圆环 + 水滴）** |

生成脚本 `_build/gen-logo-marks.py` 三种模式：
- `dark`：白底深色图标，`alpha = 255 - min(r,g,b)`。
- `light`：深色底白图形（招行一网通方标）。
- `color`：**v1.2 新增**，彩色实底图标按「到白底欧氏距离」取墨量，避免 `dark` 把亮蓝压成半透明灰白。

位图行徽统一降采样 64×64 后按行行程编码成 4 档透明度的纯 `path` SVG，**不内嵌 base64 位图**（浏览器渲染会卡死，且不是真矢量）。卡面生成时内联，SVG 自包含。

**复用关系**：京东系（白条 / 小金库）用京东标，抖音系（放心借）用抖音标，e招贷用招行标；现金与个人借款无 logo，降级文字标。
**v1.2 变更**：余额宝、花呗不再复用支付宝标，各自用独立图标。

## 六、遗留与风险

1. **法律风险**：logo 是注册商标。本地自用在自己的记账 App 里无碍；若上架 App Store，需换回「品牌色块 + 银行名简称」（`brands.json` 已有 `short` 字段）。
2. **京东行徽是文字标**：`logo-jd.svg` 裁出的是「京东」两个中文字而非 JOY 图形，在暖色卡面上偏淡。以后可换图形标，不影响数据形状。
3. **卡面比例未统一**：`brands.json` 用 148×93（1.586），原型是 148×92（1.609）；差 1.5%，历史遗留待定。
4. **精选集是否全量进包**：492 个图标 15.2 MB vs 常用 40 个 1.3 MB，历史遗留待定。
