记一笔入口 · B / C / D 对比

三版共用同一份首页（顶部 T1 tab、四层卡堆、便签、层厚 10pt），只换入口。第四格是三版点下去之后的同一屏——入口长什么样，取决于点进去发生什么。

这一轮不做什么

不再做悬浮块。上一轮四版（重圆 / 文字胶囊 / 金额胶囊 / 卡内纸签）都被判「和首页风格不符」，根因是它们都是贴在纸上的物体。这三版都改成结构：一行、一条页脚、一枚页签。

三版都满足：不压层厚带（38→8）、不挡便签、与顶部 tab 同一套材质、点击后进入同一张记账页。

三版的真实差别（不是审美，是结构）

  • B 是唯一「入口即内容」的：它和 8 条流水行共用同一套节奏（42 槽 + 14pt 字），所以读起来不像按钮。代价是它在卡片里，翻卡时跟着走——但这正好是它支持补记的原因。
  • C 是唯一「永远在同一个像素位置」的：不随卡、不随滚动。适合「打开就记一笔、记完就走」的习惯；但它是全局的，历史日补记要靠额外的日期选择。
  • D 是唯一「完全不占版面」的：伸出卡外 10pt，不吃卡内高度也不吃屏幕底部。但 28×64 的命中区在 390pt 屏上偏窄，而且贴右缘，iOS 的边缘返回手势会和它抢。
