三条连带影响（实测，非目测）

① B 纯白：页底与白卡色差 0%，卡片边界只能靠 inset 描边 + 阴影 撑起来；这也是规格第 226 行「白页头 + 白卡片连成一片」的风险点。
② F 深暖灰：若沿用旧 tab 槽 #EBE7E0，与页底色差只有 3.7%，直接踩中「浅色容器浮白卡色差 <5% 必然糊」→ 槽色必须同步加深到 #DFD9CD（16.3%）。
③ A 现状：sub #A8A39A 在白卡上只有 2.51:1；faint #C6C2B9 1.78:1 只能降级为装饰色。B–F 已把辅助文字全部拉到 ≥4.5:1，视觉上灰字会明显变深。

技能与优先级

本轮调用 ui-ux-pro-max（color / style / ux / swiftui）与 ios-hig-design（44pt / 4.5:1 / 11pt / Dynamic Type），只取可用性规则与两个中性底色候选；其 Web 专属结论（落地页结构、Claymorphism、Google Fonts、禁 emoji 图标、hover/cursor/多断点、系统语义色替代硬编码）一律不采用。优先级：AGENTS.md > PRD v2.3 > 四份冻结规格 > skill 通用建议。
