tab 材质 · 五版对照

同一套卡堆（散叠 3 层、层厚 10pt、白卡）+ 便签「本月 ↘12.4%」，只换底部导航的材质，不动位置、不动数量、不动图标。

先说诊断：现在的墨键为什么不搭

不是位置问题（D2 那轮已验证「只压前卡、层厚带完整穿过」是对的），是材质和重量问题。

整页的语言是「暖白 #F7F5F1 + 白纸卡 + 极轻双层阴影 + 若有若无的层叠」，强调色用量不到 5%（红只给支出）。而墨键是 #1D1C1A 纯黑实心胶囊 126×40——它是全屏第二重的元素（仅次于 FAB），一个孤立的、和纸毫无关系的黑色硬件。

HeyCost 那类 App 的 tab 几乎不可见。墨键比它重太多，也比 DooDoo 自己的纸卡语言重太多。这就是"不搭"的来源。

A无容器 · 浅底托轻
每个图标一枚 34pt 浅底圆角方托（和 emoji 的 42px 浅底容器同一套语言），选中项底托转白 + 加深 + 顶部一条 12pt 墨线。
零胶囊，重量最轻，但仍压在层叠边缘上，需要底托托住才读得清。
B三张独立纸签推荐
三张 40×36 独立小纸签，选中那张填墨（不是抬起——白底上抬起读不出来）。
与卡堆同一套纸材质：描边 + 窄投影。三个按钮读得清，且黑签与右侧黑 FAB 同族，两个重物呼应而非割裂。
C玻璃胶囊白浮白
玻璃 + 淡墨图标，最接近 index.html 最初的形态。
实测不成立：底色 rgba(246,243,238,.92) 与白卡只差 2%，胶囊边界读不出，读成"白卡上贴了张白纸"。白浮白行不通这条老教训又一次复现。
D墨键（现状）对照组
纯黑实心胶囊 + 独立黑 FAB。
两个纯黑重物分居两端，中间 178pt 空地。两个黑物之间没有任何材质呼应——这才是"不搭"的真正来源，不是位置。
E顶栏 · 底部只留 +最干净
tab 进页头右侧（18px 细线图标 + 选中墨点），底部只留 FAB。卡堆层叠零遮挡。
代价：单手够屏幕顶最难，而资产页是重度页面；页头还要给便签让位（.vE .note{top:6px}）。

结论备选推荐否否（现状）备选

为什么 B 是推荐：它同时解掉两个问题

  • 材质归位：纸签用与卡堆后层完全相同的配方（0 0 0 1px rgba(29,28,26,.13) + 0 2px 4px rgba(29,28,26,.06)），所以它读成"另一张小纸"，而不是"贴在纸上的黑色控件"。
  • 两个黑物互相呼应：选中签填墨后与右侧黑 FAB 同为 #1D1C1A，重量对等、语义不同（导航 vs 主动作），不再是两个互不相干的黑块。
  • 选中态用填墨不用抬起：白纸签上"抬起 4pt"完全读不出来（第一版实测），只有填充色变化是明度差，稳。
  • 不做玻璃：白卡 + 玻璃 = 白浮白，2% 色差。这条老教训已经复现过一次，不要再来第三次。
