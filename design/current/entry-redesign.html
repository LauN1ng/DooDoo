主色

参考三图后的改法

这三个界面共用一套语言：浅灰底 + 白色大圆角卡片 + 3D 图标的大色块 + 巨大的彩色金额 + 自带功能列的键盘。之前那版是「白纸 + 细线 + 克制的灰」，方向正好相反。

逐项对应

  • 顶部分段：支出 / 收入 / 还款 / 转账（照图 2 的胶囊，不是纯文字）
  • 分类：4×2 大色块 64×64 圆角 18，选中实色填充 + 外圈描边（图 1）
  • 金额：44pt 粗体 + 主色，不是黑色（图 1 绿 / 图 2 橙 / 图 3 蓝）
  • 备注卡：白卡圆角 18 + 虚线分隔 + 「选择账户 ›」（图 1）
  • 键盘：3 列数字 + 右侧功能列（删除 / 今天 / 保存长条）（图 1）
  • 「再记」胶囊：浅主色底（图 1 右上）

没照搬的

  • 二级分类：PRD 定死 8 类，v1 没有二级，所以只有一层
  • 相机 / AI 助手：不在 v1 范围
  • 模板行：需要新数据能力，先不做
