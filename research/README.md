## 二、已确立的「可抄 / 不可抄」

| 可抄（骨架） | 不可抄（差异点） |
|---|---|
| 流水列表：日期分组、行高 ~56pt、金额右对齐 | Fluent 3D Emoji 的用法 |
| 记一笔：键盘布局、分类九宫格、默认值记忆 | 「还款不计支出」的视觉表达 |
| 账户列表：分组折叠、额度使用条 | 满宽卡堆、sheet 式浮层（本项目已否决） |
| 还款页：逾期置顶、按到期日排序 | 国内记账 App 的卡通 IP + 绿色渐变头图 |

**结论**：市面没有任何 App 实现「还款关联到具体某一期账单」，也没有「一个信用账户下挂多个分期」的建模，这两块必须自己写（PRD 9A R2）。

## 三、纪律

- 素材只追加，不删（判断过的否定结论同样有价值）。
