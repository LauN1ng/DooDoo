## 硬规则

- 纯函数：不依赖 SwiftData、不依赖 UI、不发网络请求，可单测。
- 每个函数的注释写清：输入、输出、边界（0 期、首末期不同、退款超过剩余、除不尽）。
- 除法必须显式舍入规则；默认余数落末期。
- 校准基准：e招贷 9,000 元 24 期反算年化 ≈16.4%，与招行公布 16.43% 相差 < 0.5%。
- 用例取自 PRD 附录真实账单（招行 8857 / 白条序列 / e招贷 / 中移金科），**不得自己编数字**。
